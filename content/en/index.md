# ☁️ OS Weather
Welcome to the **official public documentation** for **OS Weather**, a server-authoritative Minecraft Overworld weather simulation by **LevelsFR**.

> **Beta status:** `0.9.0-beta.10.5` is a pre-v1 candidate, not a stable release. **Public API:** v1. **License:** proprietary, All Rights Reserved.

## What OS Weather offers
- Local atmospheric weather rather than a single world-wide vanilla weather flag
- Server-controlled weather with smooth, per-player client transitions
- A 512-block atmospheric grid, climate-driven scenarios and persistent conditions
- Separate visual and gameplay weather state with public integration hooks
- Integration points for other dimensions using registered weather providers
