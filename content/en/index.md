# OS Weather

**OS Weather** is a server-authoritative local atmospheric weather simulation for Minecraft's Overworld.

> **Pre-release:** the mod is `0.9.0-beta.10.5`, not a stable V1. Its public API is revision **1**; the API revision and the mod release version are independent.

Local verification on 2026-10-14: all six configured variants (Minecraft 1.21.1, 26.2 and 26.3 on Fabric and NeoForge) assembled, and each core smoke check passed 47 scenarios. Game launch, world entry and dedicated-server tests remain outstanding.
