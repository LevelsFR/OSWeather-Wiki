# Stable V1 release status

**Mod version:** `1.0` · **Release type:** stable · **API revision:** `1`

The author confirms that OS Weather is ready for its final V1 release.

## Stable release targets

The stable V1 release targets Minecraft 1.21.1, 26.2.x and 26.3.x on both Fabric and NeoForge. See the [compatibility matrix](compatibility.md) for Java versions and matching runtime builds.

## CurseForge availability

The CurseForge page currently lists only the earlier `1.0-beta` file for Minecraft 1.21.1 on NeoForge. Stable `1.0` packages should be downloaded there once listed. This page records the stable release status and supported target matrix; it does not claim that the stable JARs are already available on CurseForge.

## Public API

The public API is at revision `1`, independently of the mod version. No standalone API JAR or Maven coordinates are published. The source repository remains private. See [API v1](api-v1.md) and [rights and permissions](rights.md).
