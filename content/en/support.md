# Support and public issue tracker
Use [OS Weather Issues](https://github.com/LevelsFR/OSWeather-Wiki/issues/new/choose) to report bugs or request features.

## Before reporting
1. Review [installation](installation.md), [compatibility](compatibility.md) and the [FAQ](faq.md).
2. Reproduce the issue with the exact Minecraft release, loader and OS Weather build.
3. Use the **Bug report** form and include Minecraft version, OS Weather version, loader name/version, Java version, client or dedicated server, steps, expected/actual result and essential logs.
4. For enhancements, use **Feature request** and explain the problem and desired public behavior.

## Protect private information
**Always redact** passwords, auth tokens, access keys, session IDs, personal data and non-public hostnames/IP addresses. Do not upload private source code, internal configuration, full sensitive server logs or unpublished assets. Staff may ask for a minimal reproducer without confidential data.

This public repository is not the source repository and is not an open-source contribution invitation.
