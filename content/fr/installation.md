# Installation

> La version stable V1 d’OS Weather est la `1.0`. Installez uniquement un fichier stable `1.0` correspondant à votre version de Minecraft et à votre loader. CurseForge ne liste actuellement que l’ancienne beta pour 1.21.1 NeoForge ; vérifiez que les fichiers stables sont disponibles avant le téléchargement.

## Installer le mod

1. [Téléchargez le fichier stable OS Weather 1.0 sur CurseForge](https://www.curseforge.com/minecraft/mc-mods/os-weather) correspondant à votre version de Minecraft et à votre loader.
2. Installez la version de Minecraft et le loader correspondant au JAR. Utilisez Java 21 pour Minecraft 1.21.1 et Java 25 pour 26.2.x/26.3.x.
3. Placez le JAR d’exécution dans le dossier `mods/` de l’instance.
4. En multijoueur, installez la même version sur le serveur et sur les clients qui le rejoignent.

N’utilisez pas un JAR de sources comme mod. Chaque combinaison Minecraft/loader nécessite son JAR d’exécution correspondant ; consultez la [matrice de compatibilité](compatibility.md) et les fichiers CurseForge.

Les paramètres client se trouvent dans `config/osweather-client.toml`. Les paramètres de simulation serveur sont dans le `config/osweather-server.toml` du serveur. L’écran de configuration facultatif n’est pas requis ; voir [configuration](configuration.md) et [compatibilité](compatibility.md).
