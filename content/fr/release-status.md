# Statut de la sortie stable V1

**Version du mod :** `1.0` · **Type de sortie :** stable · **Révision API :** `1`

OS Weather est la sortie stable V1, version `1.0`.

## Cibles de la sortie stable

La sortie stable V1 cible Minecraft 1.21.1, 26.2.x et 26.3.x sous Fabric et NeoForge. Consultez la [matrice de compatibilité](compatibility.md) pour les versions Java et les JAR correspondants.

## Disponibilité sur CurseForge

CurseForge n’affiche pas encore les fichiers stables `1.0` pour toute la matrice. Vérifiez la version Minecraft et le loader indiqués sur la page de téléchargement. Cette page décrit les cibles stables ; CurseForge indique les fichiers d’exécution réellement disponibles.

## API publique

L’API publique est à la révision `1`, indépendamment de la version du mod. Aucun JAR API autonome ni coordonnées Maven ne sont publiés. Le dépôt source reste privé. Voir [API v1](api-v1.md) et [droits et permissions](rights.md).
