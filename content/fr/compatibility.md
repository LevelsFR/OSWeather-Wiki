# Compatibilité

**Version stable du mod :** `1.0` · **Statut :** sortie V1 stable

La sortie stable V1 cible les combinaisons Minecraft et loader suivantes :

| Minecraft | Loader | Java | Version stable |
|---|---|---:|---|
| 1.21.1 | Fabric | 21 | `1.0` |
| 1.21.1 | NeoForge | 21 | `1.0` |
| 26.2.x | Fabric | 25 | `1.0` |
| 26.2.x | NeoForge | 25 | `1.0` |
| 26.3.x | Fabric | 25 | `1.0` |
| 26.3.x | NeoForge | 25 | `1.0` |

Chaque combinaison nécessite son JAR d’exécution correspondant. La [page CurseForge](https://www.curseforge.com/minecraft/mc-mods/os-weather) n’affiche pas encore les packages stables `1.0` pour toute la matrice. Vérifiez la version Minecraft et le loader indiqués sur le fichier avant de le télécharger.
