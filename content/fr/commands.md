# Commandes
OS Weather propose la famille `/osweather` pour consulter et administrer la météo.

| Commande | Fonction |
|---|---|
| `/osweather status` | Afficher l’état général |
| `/osweather info` | Consulter les détails atmosphériques |
| `/osweather debug` | Diagnostic et débogage |
| `/osweather set` | Demander un override météo |
| `/osweather clear` | Supprimer un override |
| `/osweather reload` | Point d’entrée pour recharger la configuration |

**Attention :** les arguments précis et permissions sont à confirmer via l’autocomplétion du build utilisé. Le rechargement à chaud **n’est pas encore garanti** dans cette préversion.

## Commandes vanilla
`/weather clear`, `/weather rain` et `/weather thunder` sont reliées aux overrides OS Weather.

Pour un problème de commande, préciser les arguments exacts, Minecraft, le loader et la version du mod dans le [rapport de bug](support.md).
