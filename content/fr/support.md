# Assistance et signalements publics
Utilisez les [Issues OS Weather](https://github.com/LevelsFR/OSWeather-Wiki/issues/new/choose) pour signaler un bug ou suggérer une fonctionnalité.

## Avant de poster
1. Consulter [installation](installation.md), [compatibilité](compatibility.md) et la [FAQ](faq.md).
2. Reproduire le problème en indiquant précisément Minecraft, le loader et le build du mod.
3. Utiliser le formulaire **Bug report** avec Minecraft, version OS Weather, loader et sa version, Java, environnement client/serveur, étapes, résultat attendu/obtenu et extrait utile des logs.
4. Pour une nouveauté, utiliser **Feature request** et décrire le besoin concret.

## Protégez les informations privées
**Supprimez toujours** mots de passe, tokens, clés, identifiants de session, données personnelles et adresses privées. Ne transmettez ni code source privé, ni configurations internes, ni logs serveur sensibles complets.

Ce dépôt public ne donne pas accès au code source et n’ouvre pas les contributions open source.
