# Documentation sources and native Wiki mirror

The bilingual website published at [OS Weather Wiki](https://levelsfr.github.io/OSWeather-Wiki/) is generated from `content/en/` and `content/fr/` and deployed from the generated `_site/` directory by GitHub Pages Actions.

Files in this `wiki-content/` directory are a convenience mirror for a future/native GitHub Wiki. GitHub's native Wiki is stored separately from this repository and is **not automatically updated** by changes here. The Pages site is the currently published canonical documentation.

The mod source repository remains private. No mod source or binary is mirrored here.
